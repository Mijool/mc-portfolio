# Miguel's Portfolio built using Astro: an All-In-One frontend framework

In lieu of hosting my academic portfolio using a drag-and-drop like Wix, I decided to use my CS background to create a lightweight site that only does exactly what I need it to do.

.astro files are similar to Razor (.cshtml) files that mix the use of standard html and server-side javascript. This framework is perfect for a portfolio as its fast and lightweight, the server really only handles loading images.
